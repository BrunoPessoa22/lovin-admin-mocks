Lovin admin mockups

Two versions of the same admin, same screens and same sample data. Only the design system changes. Pick one and the build follows it.

Mock 1 · Preline UITailwind CSS v4 and Preline's component classes and theme tokens. Dense, conventional, Tailwind-native. Mock 2 · HeroUI v3HeroUI's React component library, here through its compiled stylesheet and tokens. Rounder, softer, React Aria under the hood.

Both pages have a dark mode toggle, an accent switch (the library default vs Lovin red), Ctrl+K search and all eight sections: Home, Review centre, Users, Marketplace, Malta Intelligence, Newsroom, Sources, Settings.
